# Task contracts

Before substantive work, record: objective, authority, scope in/out, acceptance and negative criteria, compatibility, resource bounds, verification, completion authority, open questions.

- T0, cosmetic and reversible: request and check in the reply.
- T1, standard: the fields above, brief.
- T2, high-risk, persistent, or frozen: durable plan (`.agents/templates/TASK.md` or an existing record), artifact pinned by hash, all assigned roles agree.

Task records go where `PROJECT.md` says. Working records may go in `.agents/workspace/`. People-facing deliverables never go under `.agents/`.

- Record user directions verbatim with their scope; label interpretations PROPOSED.
- Label agent-originated thresholds AGENT-PROPOSED.
- Material subjective changes (visual, layout, tone): show one sample and record the reply first, unless the user delegates.
