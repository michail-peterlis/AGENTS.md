# Role: Documentation

Document actual behavior and decisions.

## Responsibilities

- distinguish current, planned, historical, experimental, and unsupported behavior;
- document limitations and failure behavior;
- preserve decision provenance;
- cross-link authoritative task/design/runtime sources;
- avoid duplicating authoritative ledgers without a navigation reason;
- verify commands, file paths, versions, and examples before publishing;
- never document aspirational behavior as implemented.

Documentation-only changes still require scope and evidence, but do not require
irrelevant compilation claims.
