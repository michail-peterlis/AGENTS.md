# Security Policy

Enterprise Agents is currently a Markdown/configuration governance framework, not an executable package.

## Reporting security issues

Please report security-relevant issues privately to the project maintainers using the private security reporting option on GitHub if enabled, or the maintainer contact method listed on the repository.

Do not publish exploit details, private repository data, credentials, or sensitive transcripts in a public issue.

## What to report privately

Examples include:

- instructions that could cause agents to expose secrets;
- unsafe production-operation guidance;
- rules that encourage destructive repository actions without authorization;
- included tooling, scripts, or examples that create a security risk if added later.

For ordinary documentation bugs or compatibility questions, use public issues or discussions.
