# Code of Conduct

## Our pledge

We pledge to make participation in this project welcoming, respectful, and constructive for everyone.

## Expected behavior

- Be respectful of differing experience levels and tool preferences.
- Critique ideas and proposed rules, not people.
- Prefer clear evidence, examples, and tradeoffs over assertions.
- Assume good intent while addressing concrete harmful behavior.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Public or private abuse of contributors.
- Publishing private information without explicit permission.
- Repeated disruption of project discussions after maintainers request a change.

## Enforcement

Maintainers may moderate discussions, close issues, request changes, or restrict participation to protect the project community.

To report conduct concerns, contact the project maintainers privately using the contact method listed on the GitHub repository.
